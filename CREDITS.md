# Image credits

The Figma mock-up's own landmark photographs could not be exported: the file is on
a Figma Starter plan and its MCP tool-call quota is exhausted, so no asset URL was
ever issued for the map pins. The photographs below stand in for them.

They are not arbitrary images off the web. Each one is a freely licensed photograph
from Wikimedia Commons, listed here with its author and licence so the attribution
obligation is met — this repository is public. Each file was cropped to a square and
resized to 400x400 so one source serves the circular map pin, the city chip and the
pinboard tile.

Replace these with the design's own photographs once the Figma quota allows it, and
delete the corresponding row here.
